# 🎧 TOEIC Speaking Trainer — 질문 듣기 훈련

토익스피킹 질문을 듣자마자 **"무엇을 묻는 질문인지"** 파악하는 능력을 만드는 훈련 프로그램.
운동 중·이동 중에 이어폰만으로 반복 학습할 수 있게 설계했습니다.

## 실행 방법

**`시작.bat` 더블클릭** (서버 실행 + 브라우저 자동 열림) — 또는 직접:

```bash
node server.js
```

브라우저에서 http://localhost:8123 접속. **API 키 없이 모든 기능이 동작합니다** (브라우저 내장 TTS 사용).

> ⚠️ `index.html`을 더블클릭해서 열면 브라우저 보안 정책 때문에 **빈 화면**이 됩니다. 반드시 `시작.bat` 또는 `node server.js`로 실행하세요.
>
> 🔊 **자연스러운 목소리**: 기본 문항 170개는 신경망 TTS로 미리 생성된 mp3(`audio/`)로 재생되어 어떤 브라우저에서도 자연스럽게 들립니다. 파일을 다시 만들려면 `음성생성.bat` 실행 (인터넷 필요, 무료). 파일이 없는 문항은 브라우저 내장 음성으로 폴백됩니다.

## 주요 기능

| 메뉴 | 설명 |
|---|---|
| 🏃 운동 모드 | 영어 질문 → 생각 시간 → 한국어 해석 → 모범답변 → 자동 다음 문제. 화면 안 봐도 됨 |
| 🎧 실전 듣기 | 음성만 듣고 의미 판단 → 질문 확인 → 알았음/몰랐음 기록 |
| 📚 파트별 학습 | Part 3/4/5 질문 목록·상세 (음성, 해석, 모범답변, 즐겨찾기) |
| ❓ 질문 유형 퀴즈 | 듣고 "시간/장소/빈도/이유…" 유형 맞히기, 오답은 취약 목록 자동 저장 |
| 🔁 취약 질문 복습 | 틀린 문제 + 복습 예정 문제만 (간이 Spaced Repetition) |
| 📊 학습 통계 | 오늘/누적, 파트별·유형별 정답률, 취약 의문사, 연속 학습일 |
| ⚙️ 질문 관리 | 추가/수정/삭제, CSV·JSON Import/Export, AI 일괄 생성(검토→승인) |

## 선택 설정 (고품질 TTS / AI 질문 생성)

`.env.example`을 `.env`로 복사하고 키를 입력하면 활성화됩니다:

- `TTS_PROVIDER=openai` — 시험 안내 스타일의 고품질 음성 (설정 화면에서 선택 가능)
- `LLM_PROVIDER=anthropic` — 관리 화면의 "AI 질문 일괄 생성" 버튼 활성화

키는 `.env`에만 저장되며 서버(server.js)가 프록시로 호출합니다. 소스코드에 키를 넣지 마세요.
